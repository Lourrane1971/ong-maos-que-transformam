# ONG Mãos que Transformam

Projeto front-end desenvolvido para a ONG Mãos que Transformam.

## Objetivo

O site tem como objetivo apresentar os projetos da ONG e permitir o cadastro de voluntários.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Funcionalidades

- Navegação entre páginas
- Exibição de projetos
- Cadastro de voluntários
- Validação de formulário
- Recursos de acessibilidade
## Instalação local

Para executar o projeto localmente:

1. Clone o repositório para o computador.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server.
4. Navegue pelas páginas da aplicação para testar suas funcionalidades.

O projeto utiliza HTML, CSS e JavaScript e não necessita da instalação de dependências externas para sua execução.

## Versionamento

O projeto utiliza Git e GitHub para controle de versão.

O desenvolvimento é organizado em branches, mantendo a `main` como branch principal e utilizando branches `feature` para o desenvolvimento de funcionalidades e documentação.

As alterações são registradas por meio de commits descritivos. Após a conclusão de uma tarefa, as branches podem ser integradas à `main` por meio de Pull Requests, permitindo revisar e documentar as alterações antes da fusão.
