# ONG Mãos que Transformam

Projeto front-end desenvolvido para a ONG Mãos que Transformam.

## Objetivo

O site tem como objetivo apresentar os projetos da ONG e permitir o cadastro de voluntários.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Funcionalidades

- Navegação entre páginas
- Exibição de projetos
- Cadastro de voluntários
- Validação de formulário
- Recursos de acessibilidade
